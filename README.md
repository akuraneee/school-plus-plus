# Schools++

Расширение для электронного дневника [schools.by](https://schools.by): считает средние баллы по предметам,
четвертные и годовые отметки (точные и округлённые), показывает динамику и другую статистику.

Работает от имени уже вошедшего пользователя: само читает страницы дневника и никуда их не отправляет.
Данные хранятся только в браузере (`chrome.storage.local`).

## Что показывает

- **Обзор**: таблица предметов × четверти (округлённая отметка + точное среднее), годовая отметка
  (среднее округлённых четвертных), среднее всех отметок, пропуски, тренд, мини-график; средний балл по четвертям;
  какие предметы почти дотягивают до следующей отметки и какие на грани понижения; распределение отметок 1–10.
- **Предмет**: отметки по четвертям, график с накопленным средним в четверти, медиана, мода, разброс,
  сколько десяток/девяток нужно до следующей отметки, какая отметка уронит текущую, калькулятор «а что если».
- **Динамика**: средний балл по неделям и накопленный с начала года, лучшая и худшая неделя, среднее по дням недели,
  изменения по предметам за 30 дней и последние 5 отметок.
- **Настройки**: порог округления (по умолчанию 0,5), полная перезагрузка, выгрузка HTML для отладки.

## Установка

Выберите своё устройство:

- [На компьютере](#на-компьютере): Chrome, Яндекс.Браузер, Edge, Opera
- [На Android](#на-android)
- [На iPhone](#на-iphone)

Установка занимает 5 минут. Ничего покупать и регистрировать не нужно.

---

### На компьютере

**1. Скачайте файл.** Нажмите на ссылку: [schools-plus-plus-chromium.zip](https://github.com/akuraneee/school-plus-plus/releases/latest/download/schools-plus-plus-chromium.zip).
Файл сохранится в папку «Загрузки».

**2. Распакуйте его.** Найдите файл в «Загрузках», нажмите на него правой кнопкой мыши → «Извлечь всё…» → «Извлечь».
Появится обычная папка `schools-plus-plus-chromium`.

> ⚠️ Переложите эту папку туда, где она будет лежать всегда, например в «Документы».
> Если папку удалить, расширение перестанет работать.

**3. Откройте страницу расширений.** Скопируйте адрес ниже, вставьте в адресную строку браузера и нажмите Enter:

| Браузер | Адрес |
|---|---|
| Google Chrome | `chrome://extensions` |
| Яндекс.Браузер | `browser://extensions` |
| Microsoft Edge | `edge://extensions` |
| Opera | `opera://extensions` |

**4. Включите «Режим разработчика».** Это переключатель на этой же странице: в Chrome он справа вверху,
в Edge — слева внизу. Ничего страшного он не делает, просто разрешает ставить расширения из файла.

**5. Нажмите «Загрузить распакованное расширение»** (появится после шага 4) и выберите папку
`schools-plus-plus-chromium` из шага 2. Выбрать нужно именно папку, а не файл внутри неё.

**6. Готово!** Откройте [schools.by](https://schools.by) и войдите в дневник. Справа внизу появится синяя кнопка
**«Статистика»**.

> Chrome иногда показывает окно «Отключите расширения в режиме разработчика». Просто закройте его крестиком
> (не нажимайте «Отключить»).

### На Android

Обычный Google Chrome на телефоне расширения **не поддерживает**. Нужен браузер, который умеет ставить
расширения от Chrome. Таких несколько, например **Lemur Browser** или **Quetta**, они есть в Google Play.
Если у вас уже есть такой браузер (например, Titanium), используйте его.

**1. Скачайте файл.** Откройте эту страницу в нужном браузере и нажмите:
[schools-plus-plus-chromium.zip](https://github.com/akuraneee/school-plus-plus/releases/latest/download/schools-plus-plus-chromium.zip). Распаковывать **не нужно**.

**2. Откройте страницу расширений.** Нажмите ⋮ (меню) → «Расширения». Если такого пункта нет, введите в адресной строке
`chrome://extensions`.

**3. Включите «Режим разработчика»** (переключатель вверху страницы).

**4. Нажмите кнопку «+ (from .zip/.crx/.user.js)»** (в разных браузерах она называется немного по-разному:
«Загрузить», «Установить из файла»). Выберите скачанный файл `schools-plus-plus-chromium.zip` в «Загрузках».

**5. Готово!** Откройте [schools.by](https://schools.by) и войдите в дневник. Справа внизу появится синяя
круглая кнопка со столбиками.

> Если кнопки нет: откройте меню браузера и включите **«Версия для ПК»**, затем обновите страницу.

### На iPhone

На iPhone расширения для Chrome не работают, поэтому используем бесплатное приложение **Userscripts**.
Оно добавляет в Safari маленькие программы для сайтов.

**1. Установите приложение.** Откройте App Store, найдите **Userscripts** (значок `</>`) и установите его.

**2. Выберите папку для скриптов.** Откройте приложение Userscripts → нажмите **«Set Userscripts Directory»**
→ выберите «На iPhone» → создайте новую папку `Userscripts` → «Открыть».

**3. Включите его в Safari.** Откройте «Настройки» → «Приложения» → «Safari» → «Расширения» → **Userscripts**.
Включите его и в «Разрешения» поставьте **«Разрешить»** для всех сайтов (или для schools.by).

> На старых версиях iOS путь короче: «Настройки» → «Safari» → «Расширения».

**4. Скачайте скрипт.** Откройте эту страницу в **Safari** и нажмите:
[schools-plus-plus.user.js](https://github.com/akuraneee/school-plus-plus/releases/latest/download/schools-plus-plus.user.js). Если Safari спросит, скачать ли файл, нажмите «Загрузить».

**5. Переложите файл в папку из шага 2.** Откройте приложение **«Файлы»** → «Загрузки» → нажмите и подержите
`schools-plus-plus.user.js` → «Переместить» → «На iPhone» → `Userscripts` → «Переместить».

> Если вместо скачивания Safari показал страницу с кодом, всё ещё проще: нажмите **«аА»** в адресной строке →
> **Userscripts** → **«Install»**. Тогда шаг 5 не нужен.

**6. Готово!** Откройте [schools.by](https://schools.by) в Safari и войдите в дневник. Справа внизу появится синяя
круглая кнопка со столбиками. Скрипт будет обновляться сам.

### Как пользоваться

1. Войдите в дневник на schools.by как обычно.
2. Нажмите кнопку **«Статистика»** справа внизу.
3. Первый раз дневник загружается примерно минуту, потом всё открывается сразу.
   Чтобы подтянуть новые оценки, нажмите **«Обновить»**.

**Как читать таблицу:** большая цифра — оценка, которая выйдет в четверти (округлённая), маленькая рядом — точный
средний балл. Например, «**8** 7,63» значит: средний 7,63, в четверти выйдет 8.
Нажмите на предмет, чтобы увидеть, **сколько десяток или девяток нужно до следующей оценки**.

### Если что-то не работает

- **Кнопки нет.** Обновите страницу. Убедитесь, что вы вошли на schools.by. На телефоне включите «Версия для ПК».
- **Пишет «вы не вошли».** Войдите на schools.by заново и нажмите «Обновить».
- **Оценки старые.** Нажмите «Обновить».
- **Ничего не помогло.** Создайте [обращение (Issue)](https://github.com/akuraneee/school-plus-plus/issues) и опишите,
  что происходит. Пожалуйста, не прикладывайте скриншоты с чужими оценками и фамилиями.

### Это безопасно?

Да. Расширение видит только тот дневник, в который вы сами вошли, и просто считает по нему средние баллы.
Оно не может открыть файлы, фото или другие приложения на телефоне и никуда не отправляет ваши данные:
всё хранится только в вашем браузере. Код открыт, его может проверить любой.

Скачивайте файлы **только по ссылкам с этой страницы**. Копия из другого места может быть изменена.

## Для разработчиков

```
src/utils.js    даты, округление, форматирование
src/parser.js   разбор HTML недели дневника (селекторы в SPP.SEL)
src/crawler.js  поиск ученика, четвертей и обход всех недель
src/stats.js    расчёты
src/charts.js   SVG-графики
src/ui*.js      панель (Shadow DOM)
test/           тесты (jsdom) и демо-данные; demo/demo.html открывает панель на выдуманных данных
samples/        сохранённые страницы schools.by (личные данные, не публиковать)
```

```bash
npm install      # jsdom для тестов
npm test         # тесты + сборка + проверка userscript
npm run build    # только сборка в dist/
```

Файлы собираются автоматически (GitHub Actions) при каждом изменении в `main` и выкладываются в Releases.

Userscript запускается в изолированном контексте (`@inject-into content`). Если в каком-то окружении запросы
к дневнику идут без авторизации, поменяйте на `@inject-into page` в `build.py`: хранилище само переключится на `localStorage`.

**Новая версия:** поднимите `"version"` в `manifest.json` и запушьте в `main`. Actions соберёт и опубликует
релиз `v<версия>`. Userscript на iPhone обновится сам (в нём прописан `@updateURL`). Расширение на компьютере
нужно скачать и распаковать заново поверх старой папки, затем нажать ↻ в `chrome://extensions`.
